What is AI?

Artificial intelligence is software that finds patterns and uses them to help with tasks, like answering questions or recognizing pictures. It can be useful, but it can also make mistakes.

✎

The art of prompting

A prompt is the instruction or question you give an AI tool. Clear context, a specific goal, and a little back-and-forth usually lead to more helpful results.

</>

A first step into code

Code is a set of instructions that tells a computer what to do. AI can explain code and help you try ideas, while you stay in charge of checking how it works.
